SHEET A-01 SCALE: NOT TO SCALE REV: BEGINNER

Learning the Revit API
with zero coding background

A six-stage path from "I've never written a line of code" to writing your own Revit add-ins — plus the shortcut, if the API isn't actually what you need.

Before you start: the Revit API is built on .NET and is normally written in C#. If none of that sentence made sense yet, that's exactly why stage one exists below — don't skip to stage four.
01
1–4 WEEKS

Learn programming logic first

Variables, loops, if/else statements, functions, and what an "object" actually is. Python is the gentlest language to learn this in, even though you'll likely end up writing C# for Revit later.

Goal: reading code should feel like reading a language, not decoding a cipher.
02
2–4 WEEKS

Learn C# basics

The Revit API is built on .NET, and C# is its standard language. Focus on classes and objects, inheritance, and collections like List<T>.

Free resources: Microsoft's own C# tutorials, or freeCodeCamp's C# course.
03
TRAINING WHEELS

Try pyRevit before raw API code

pyRevit is a free toolkit that runs Python scripts inside Revit, with a far gentler curve than a full C# add-in. It gets you real automation working before you understand everything happening underneath.

04
SETUP

Set up the dev environment

Install Visual Studio (the free Community edition works fine) and locate the Revit API SDK — it ships with your Revit install or is downloadable from Autodesk.

Learn what an IExternalCommand is and how Revit loads an external add-in — this is the doorway into everything else.
05
FIRST WINS

Start with tiny, working examples

The classic sequence: a button that shows a message box, then a script that creates a single wall, then one that lists every door in a project. Small, verifiable wins beat ambitious failures.

06
CORE CONCEPTS

Learn the Revit-specific vocabulary

Almost everything that modifies a model needs a Transaction. Elements are queried with a FilteredElementCollector. And parameters split into instance, type, and built-in parameters.

Keep Autodesk's offline Revit API help file (.chm) close — it becomes essential past this point.
STAGE 0, REVISITED

Or skip the code entirely

If your real goal is getting something done in Revit rather than becoming a developer, an AI assistant with Revit tools connected can create elements, run schedules, batch-rename, audit models, and export data directly — no C# required. Worth checking before you commit weeks to learning to code.
