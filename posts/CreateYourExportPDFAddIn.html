Export Views/Sheets — Revit Add-in

A Revit add-in that exports a checklist-selected set of sheets and/or views to PDF or DWG, with file names built from Sheet/Project Parameters or Global Parameters, combined or one-file-per-item, to a folder you pick — with a progress bar and a per-item log.

What it does

  1. Checklist — tabs for Sheets and Views, each with checkboxes, a Check All / Uncheck All, and a name filter box.
  2. Custom naming — build a file-name template out of tokens: Sheet Number, Sheet Name, View Name, static text (e.g. _, Rev A), any Sheet/Project Parameter found on the selected items, or any Global Parameter in the project. Tokens are added in order and a live preview shows the resulting name for the first checked item.
  3. Format — PDF or DWG.
    • PDF: paper size, and Combine truly merges all selected sheets/views into one PDF (PDFExportOptions.Combine = true).
    • DWG: pick an existing DWG export setup from the project, or use Revit's default. Note: the Revit API has no “merge to one DWG” option — each view always exports as its own DWG file, even with Combine checked. The add-in reports this in the log.
  4. Output path — folder browser, created automatically if missing.
  5. Progress — a progress bar, a running status label, and a results log (OK/FAILED per item) shown after the run.

Project layout

RevitExportAddin.addin      Revit add-in manifest
RevitExportAddin.csproj     Project file (net48, WPF + WinForms)
Command.cs                  IExternalCommand entry point
MainWindow.xaml(.cs)        The UI
Models/ExportItem.cs        Checklist row (wraps a ViewSheet or View)
Models/NamingToken.cs       One piece of the naming template
Services/NamingService.cs   Resolves a template into a sanitized file name
Services/GlobalParameterService.cs   Reads document Global Parameters
Services/ExportService.cs   PDF/DWG export + progress events

Setup

  1. Set the Revit API reference path. Open RevitExportAddin.csproj and change RevitAPIPath to your Revit install folder, e.g. C:\Program Files\Autodesk\Revit 2024. Alternatively, set a machine environment variable named RevitAPIPath.
  2. Match target framework to your Revit version:
    • Revit 2021–2024 → net48 (already set).
    • Revit 2025+ → change TargetFramework to net8.0-windows.
  3. Open the folder in Visual Studio (or run dotnet build) and build. The build copies RevitExportAddin.addin next to the DLL.
  4. Copy the built .addin file and output binaries to: %AppData%\Autodesk\Revit\Addins\<version>\ and make sure the <Assembly> path points to your DLL.
  5. Start Revit, open a project, run the command from the Add-Ins tab.

Notes / things you may want to extend

  • Reordering naming tokens: current order follows add sequence; remove and re-add to reorder. Adding up/down buttons on TemplateList is a small extension.
  • Parameter list source: “Sheet/Project Parameter” is populated from parameters found on loaded sheets/views (project + shared parameters exposed via Element.Parameters).
  • PDF export API availability: PDFExportOptions / Document.Export(..., PDFExportOptions) requires Revit 2022+. Revit 2021 and earlier need a PrintManager fallback path.
  • DWG combine: true single-file DWG merging is not exposed by Revit API; only PDF supports native combine.
